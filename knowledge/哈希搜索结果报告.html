📋 笔记知识覆盖总结

✅ 已有覆盖的哈希话题

  1. HMAC 签名机制（AKSK 和 JWT）

    • 工作原理：密钥 + 消息 → 固定长度摘要
    • 实际应用：API 签名、JWT 验证

  2. SHA-256 算法（AKSK 和 JWT）

    • 用于 HMAC-SHA256 组合
    • AWS Signature Version 4 中的应用

  3. RSA 非对称签名中的哈希（JWT）

    • RS256 = RSA-SHA256 对比 HS256 = HMAC-SHA256
    • 非对称 vs 对称签名的选择

  4. 内容完整性检查（CDN、CSP）

    • 文件哈希命名（内容一致则缓存永不更新）
    • CSP 脚本哈希验证

  5. 签名生成与验证流程（AKSK 和 JWT）

    • 四步工作流：规范化 → 哈希 → 签名 → 验证
