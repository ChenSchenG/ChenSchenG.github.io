SQL 注入（SQL Injection）

一句话本质
SQL 注入是用户输入篡改了 SQL 语义：数据和指令混在一条字符串里，攻击者闭合引号改写逻辑。防御靠参数化查询。

相关原子概念
XSS · CSRF · SSRF

SQL 注入和 XSS 是同一个"注入"本质的不同投影——XSS 注入 HTML/JS，SQL 注入注入 SQL。SSRF 注入的是 URL/协议。统一防御原则：在每一层边界上将数据和指令分离。
